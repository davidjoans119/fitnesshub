# Fitness Hub — Gym Website Demo

A responsive single-page website concept for **Fitness Hub Gym, Howrah**, based on the supplied visual references (dark athletic styling, bold condensed typography and lime accents).

## Preview locally

1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Internet access is required for Google Fonts and the remote illustrative photography.

## Included

- Responsive mobile navigation
- Hero section and conversion-focused calls to action
- Training focus cards
- Training journey and gym photo gallery
- Membership enquiry section
- FAQ accordion
- Enquiry form with front-end validation
- Floating demo assistant with quick questions
- Google Maps link to the supplied listing

## Before publishing for the gym

This is a **demo**, not a verified official website. The supplied Maps short link resolves to the listing name **Fitness Hub Gym** in Howrah. Exact street address, phone/WhatsApp number, current opening hours, membership rates, trainer names, and confirmed facilities/services were not reliably available during research.

Please replace or confirm:

- Actual gym photos (current gallery images are illustrative stock photography)
- Phone / WhatsApp number and email
- Exact address and current opening hours
- Membership plans and prices
- Confirmed services, equipment, coaches and trial-session availability
- Business-approved logo and brand colours, if available

The enquiry form currently validates and displays a demo confirmation only; it does not send data to the business. Connect it to the owner's WhatsApp, email, CRM or backend before launch. The assistant is a scripted demo, not a connected AI service.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `script.js` — navigation, enquiry demo and assistant interactions
